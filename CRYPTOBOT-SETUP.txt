Baby Gift — локальный запуск с Crypto Pay

1. Установи Node.js 18 или новее.
2. Скопируй .env.example в .env рядом с cryptopay-server.mjs.
3. Вставь токен Crypto Pay API в CRYPTO_PAY_API_TOKEN.
4. Для тестовых счетов оставь CRYPTOPAY_TESTNET=1. Для реальных счетов переключи на 0.
5. Запусти в этой папке: node cryptopay-server.mjs
6. Открой http://127.0.0.1:8787 (не file://).

Токен хранится только на сервере и не включён в HTML. Этот локальный прототип начисляет оплаченные билеты в локальном хранилище браузера. Для публикации в Telegram и постоянной работы нужны HTTPS, проверка Telegram Mini App initData, база данных и отдельное подключение Telegram-бота.
